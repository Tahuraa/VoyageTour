
## Declaration

 This project was developed with the assistance of an AI coding tool, **Claude Code** (built on Anthropic's Claude models), used as a development assistant throughout the implementation of this project.

## How AI was used

- **Feature implementation**: Writing and modifying Flutter (Dart) frontend code and Node.js/Express/MongoDB backend code for features including authentication, tour search and customization, booking and Stripe payments, trip management and refund logic, in-app notifications, an offers/promotions system, and an admin dashboard.
- **Debugging**: Diagnosing and fixing bugs discovered during live testing on a physical Android device (e.g., UI overflow issues, a `setState`/`Future` misuse, a booking-status display bug).
- **UI/UX iteration**: Refining the app's visual theme and fixing resulting styling regressions.

## What was not delegated

- All functional requirements, feature scope, and design decisions (e.g., the hotel-category and refund-tier logic, the notification and promotions UX) were specified and directed by me throughout the session.
- Every feature was verified by me through live testing on a physical device and/or direct API testing before being accepted as complete.
